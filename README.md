## 🛠️ Technology Stack

| Layer | Technology | Description |
|---|---|---|
| **Core Framework** | React 19 (`react`, `react-dom`) | Modern component architecture with concurrency features |
| **Language** | TypeScript (~6.0) | Strict type checking, type safety, and interface modeling |
| **Build & Dev Tool** | Vite 8 (`@vitejs/plugin-react`) | Lightning-fast HMR and optimized production bundling |
| **Styling & Theme** | Tailwind CSS v4 (`@tailwindcss/vite`) | Utility-first CSS engine with custom design tokens |
| **Animations** | Framer Motion (`framer-motion`) | Physics-based micro-interactions, scroll reveals, and page transitions |
| **Iconography** | Lucide React (`lucide-react`) | Clean, modern, scalable vector iconography |
| **Routing** | Custom Reactive Client-Side Router | Hash-based navigation with browser history sync & animated transitions |
| **Linting & Quality** | Oxlint (`oxlint`) | Ultra-fast Rust-based linter |

## 🎨 Design System & Visual Aesthetics

- **Deep Space Black (`#020712`, `#010308`)**: Primary background layers providing immense contrast and OLED depth.
- **Cyber Cyan (`#00D9FF`)**: Primary accent for zero-trust security, AI intelligence, and main interactive actions.
- **Neon Lime Green (`#8CC63F`)**: Dedicated theme for quantum messaging, verified certifications, and encryption status.
- **Royal Amethyst Violet (`#A855F7`)**: Dedicated theme for spatial generative fashion, 3D mesh, and neural styling.
- **Slate Text Hierarchy (`#F5F7FA`, `#A8B4C3`, `#667789`)**: High-legibility typography optimized for dark interfaces.

### Visual Effects & Micro-Interactions
- **Glassmorphism**: Multi-layered backdrop blurs (`backdrop-blur-md`, `backdrop-blur-xl`) with gradient borders.
- **Dynamic Shimmer**: Cursor hover light sheen sweeps across cards.
- **Radar & Orbit Sweeps**: Continuous rotating CSS keyframes and radar sweeps.
- **Live Status Pulsers**: Blinking telemetry and heartbeat indicators for zero-trust status.

## 💻 Getting Started & Local Development

### Prerequisites
- **Node.js**: v18.0 or higher
- **npm** / **yarn** / **pnpm**

### Installation
```bash
# Clone or navigate to the repository directory
cd d:/PROJECTS/sdp/sdp_security_portal

# Install dependencies
npm install
```

### Development Server
```bash
# Start the local development server with Hot Module Replacement (HMR)
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### Production Build & Validation
```bash
# Run TypeScript type check and compile production bundle
npm run build

# Preview the production build locally
npm run preview
```

### Linting
```bash
# Run fast Oxlint checks
npm run lint
```
